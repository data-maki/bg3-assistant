Privacy policy

BG3 Honor Mode Assistant has no ads, analytics, tracking SDKs, developer account system, or developer-operated server. Your run data is stored on your Mac.

Data stored on your Mac

The app saves run names, party choices, builds, route progress, outcomes, equipment state, imported builds, and settings in your Application Support directory. An OpenRouter API key, if you add one, is stored in macOS Keychain. The developer does not receive these files or the key.

Local Qwen

If you choose Local Qwen, the app downloads the qwen3:4b model and runs it through the bundled Ollama runtime on this Mac. Chat prompts and imported build text stay local after the model download.

OpenRouter

If you choose OpenRouter, the app sends your question and the selected guide and run context needed to answer it to OpenRouter for processing by google/gemini-3-flash-preview. A build import also sends the public URL and readable text extracted from that page. OpenRouter can associate requests with the API key and account you provide. Its handling and retention are governed by OpenRouter's privacy policy and the selected model provider's terms.

Optional screenshot

With Screen Recording permission, OpenRouter chat can prepare one screenshot of a running Baldur's Gate 3 window. You see the screenshot first and can remove it. It is sent only when you send that message. Local Qwen does not accept screenshots. The app does not capture or record the screen in the background.

Speech input

Dictation uses Apple's Speech framework. The app requests Microphone and Speech Recognition permission only when needed. macOS may send audio to Apple's speech service when on-device recognition is unavailable. Apple's processing is governed by Apple's privacy policy.

Other network requests

The app uses the network to download the optional Qwen model, fetch a public build page you ask it to import, call OpenRouter when selected, and open public map handoffs. The bundled Ollama helper listens only on 127.0.0.1:11435 for requests from this app.

Deletion and retention

Delete individual runs and provider credentials from the app where those controls are available. Removing the app does not automatically remove its Application Support data or downloaded model. Email support for help removing all local app data. Data sent to OpenRouter, a model provider, or Apple is subject to that provider's retention policy.

Changes and contact

This page will be updated when the app's data practices change. Questions can be sent to jcllobet@gmail.com.

BG3 Honor Mode Assistant does not sell personal data or track users across apps or websites.
