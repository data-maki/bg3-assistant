## Remaining original map/release evidence

1. Launch BG3 in windowed/borderless mode, load a save, and leave the Wilderness map visible.
2. Export the current marker queue and observe its exact labels in the click-through overlay.
3. Use the external Computer Use session to create and name the custom markers; stop on any non-map UI.
4. Pan once, zoom once, and change window geometry once; verify markers/overlay remain aligned, then confirm the fingerprint as placed.

These observations remain release follow-ups for the original in-game marker workflow; they do not block the completed `updated_goal.md` roster, route, loadout, chat, or optional-Visual-Memory scope.

Public distribution additionally requires publisher-owned release inputs that are not present in the repository: a Developer ID Application certificate and notarization keychain profile. The permanent bundle ID is now `com.datamaki.BG3HonorAssistant`; `mac/scripts/build-release.sh` fails closed on the remaining requirements when `REQUIRE_RELEASE_SIGNING=1`.

Optional Live Events/mod distribution is deferred and must use a separate future acceptance plan before it returns to release scope.
