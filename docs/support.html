Support

How can I help?

Email jcllobet@gmail.com. Include the app version, macOS version, what you expected, and what happened. Never include an OpenRouter API key.

The planner is not visible

Open BG3 Overlay again from the Dock, Applications, or its menu bar item. The planner can be opened without running Baldur's Gate 3. Check Settings if "Show overlay while BG3 is running" was turned off.

Local Qwen is not ready

Local Qwen needs a one-time model download of about 2.5 GB. Keep the app open while it downloads. Check available disk space and network access, then retry from Settings. After installation, prompts are processed on this Mac.

OpenRouter is not ready

Use your own OpenRouter API key and make sure the account has enough credit for the selected model. The key is stored in macOS Keychain. Remove and replace it from Settings if it was revoked.

Microphone or screenshot access

Dictation needs Microphone and Speech Recognition access. A game-window screenshot is optional and only works with OpenRouter. macOS controls these permissions in System Settings under Privacy & Security. The app does not run a background recording or capture loop.

Guide corrections

Difficulty changes and unusual story branches can make a recommendation incomplete. Send the difficulty, act, route step, game patch, and the outcome you observed. The guide is planning support, not a guarantee against every patch or party choice.
